# Visual QA Skill

Use this skill whenever modifying or creating user interfaces, web layouts, HTML, CSS, React, Vue, or Svelte components.

## Verification Checklist
1. Render desktop preview at 1280x800 resolution.
2. Render mobile preview at 375x667 resolution (iPhone SE viewport).
3. Confirm zero horizontal scrollbar on mobile.
4. Confirm zero console errors and asset 404s.
5. Embed screenshot results in the response artifact.
